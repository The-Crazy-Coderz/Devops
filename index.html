Task 1: Installing and Setting Up Git for Version Control

 Problem Statement:
Install and configure Git for version control to manage 
source code versions and collaborate on projects.

 Steps to Complete:

    Download and install Git on your local machine.
    Configure Git with your user details (name, email) 
    and set up a new repository.
    Initialize a repository and commit a simple project 
    (e.g., a basic HTML page).
    Push the project to GitHub or GitLab.

 Tools/Datasets/Platforms:

    Git
    GitHub or GitLab

You can use any tool/data.
